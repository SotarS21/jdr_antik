## 🛠️ Procédure pour Ajouter Manuellement via Foundry

1. **Ouvrir Foundry VTT**
2. **Aller dans le compendium "Avantages"**
3. **Éditer un avantage** (ex: "Guerrier Aguerri")
4. **Aller dans l'onglet "Effects"**
5. **Cliquer sur "Add Effect"**
6. ** Configurer :
   - **Name**: Nom de l'effet (ex: "Guerrier Aguerri")
   - **Icon**: `icons/svg/aura.svg`
   - **Transferable**: ✅ Coché
   - **Changes**: Ajouter les modifications
     - Key: `system.attackBonuses.armeBlanche.bonus`
     - Mode: `Add` (ou valeur 2)
     - Value: `2`
7. **Sauvegarder**
8. **Répéter** pour chaque avantage
